# 🐍 Snake Game

A modern, responsive Snake web game built with React, TypeScript, Vite, and Tailwind CSS.

## ✨ Features

- 🎮 **Classic Snake Gameplay** — Navigate the snake to eat food and grow longer
- ⌨️ **Keyboard Controls** — Arrow keys or WASD to move, Space to pause, Esc to restart
- 📱 **Touch Controls** — Swipe gestures + on-screen D-pad for mobile
- ⏸️ **Pause & Restart** — Full game state management
- 🎯 **3 Difficulty Levels** — Easy, Medium, and Hard speeds
- 🏆 **Score Tracking** — Current score and persistent high score (localStorage)
- 🎨 **Modern UI** — Dark theme with smooth animations and glowing effects
- 📐 **Responsive Design** — Works great on desktop and mobile

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/snake-game.git
cd snake-game

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## 🎮 How to Play

| Action | Desktop | Mobile |
|--------|---------|--------|
| Move | Arrow Keys / WASD | Swipe or D-Pad buttons |
| Pause | Space / Esc | Pause button |
| Restart | Space / Esc | Restart button |
| Start | Space / Click | Click "Start Game" |

## 🛠️ Tech Stack

- **React 18** — UI framework
- **TypeScript** — Type safety
- **Vite** — Build tool
- **Tailwind CSS 4** — Styling
- **localStorage** — High score persistence
